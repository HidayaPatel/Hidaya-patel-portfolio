Stock Price Prediction ML Pipeline

Machine Learning  ·  Financial Analytics  ·  Deployment

Overview

This project delivers a complete, production-ready machine learning pipeline for predicting short-term stock price movements. By combining rigorous feature engineering with interpretable modeling, it bridges the gap between raw financial data and actionable trading signals. The pipeline processes historical OHLCV data, derives 28 hand-crafted technical indicators, trains and compares multiple models, and surfaces predictions through an interactive Streamlit dashboard.

The emphasis throughout was on interpretability: SHAP (SHapley Additive exPlanations) values reveal exactly which indicators drove each individual prediction, giving analysts confidence in the model's reasoning rather than just its output.

Key Features

  • 28 Technical Indicators — RSI, MACD, Bollinger Bands, ATR, OBV, moving averages, momentum, and more, all engineered from raw price data.
  • Multiple Model Comparison — XGBoost, Random Forest, Logistic Regression, and SVM evaluated with walk-forward cross-validation to prevent data leakage.
  • SHAP Interpretability — Feature importance and individual prediction explanations via SHAP waterfall and beeswarm plots.
  • Financial Backtesting — Strategy simulation with realistic transaction costs, measuring Sharpe ratio, max drawdown, and cumulative returns.
  • Streamlit Dashboard — Live, interactive visualization of signals, indicator values, and model confidence for any ticker symbol.

Tech Stack

Python XGBoost SHAP Streamlit Scikit-learn Pandas NumPy Matplotlib yfinance

Results

The XGBoost classifier achieved the best performance across walk-forward validation folds. SHAP analysis identified RSI, 20-day Bollinger Band width, and MACD histogram as the top three predictive features. The backtested trading strategy demonstrated a positive risk-adjusted return profile, outperforming a simple buy-and-hold benchmark on the test period, while maintaining interpretable decision boundaries through SHAP explanations.
