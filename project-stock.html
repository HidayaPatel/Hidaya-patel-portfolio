Stock Price Prediction ML Pipeline

Machine Learning · Financial Analytics · Deployment

Overview

This end-to-end machine learning pipeline predicts stock price movements using a rich set of 28 technical indicators derived from historical OHLCV data. The project covers the full data science lifecycle — from feature engineering and model selection to interpretability and live deployment via a Streamlit dashboard. Multiple classification models were evaluated and compared, with XGBoost emerging as the top performer. SHAP values provide transparent, stakeholder-friendly explanations of each prediction, while financial backtesting metrics validate real-world viability.

Key Features

  • 28 Technical Indicators including RSI, MACD, Bollinger Bands, EMA, ATR, and more
  • Multiple Model Comparison across XGBoost, Random Forest, Logistic Regression, and SVM
  • SHAP Interpretability for transparent, feature-level prediction explanations
  • Financial Backtesting with Sharpe ratio and maximum drawdown analysis
  • Live Streamlit Dashboard for interactive visualization and real-time exploration
