Regression Analysis — Starbucks Sugar Content

Statistical Analysis · R · Data Science

Overview

This project applies linear regression to a comprehensive Starbucks nutritional dataset, investigating which nutritional factors are most strongly associated with sugar content across the menu. Using R and the tidyverse ecosystem, the analysis covers full model specification, diagnostics, residual checks, and feature significance testing. Visualizations built with ggplot2 communicate findings clearly, revealing the top predictors of sugar content and offering insights relevant to menu transparency and dietary awareness.

Key Features

  • Nutritional factor regression analysis across the full Starbucks menu dataset
  • Full model diagnostics including residual plots and Q-Q analysis
  • Feature significance testing with p-values and confidence intervals
  • Data visualization with ggplot2 for intuitive result communication
  • Identification of top sugar predictors and their relative importance
