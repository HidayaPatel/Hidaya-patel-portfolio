K-Means Clustering — COVID-19 Severity in Ontario

Unsupervised Learning  ·  Public Health Analytics

Overview

This project applies unsupervised machine learning to categorize the severity of COVID-19 outbreaks across Ontario's public health regions. By combining K-Means and Hierarchical clustering techniques, the analysis reveals natural groupings of regions based on case counts, hospitalization rates, fatality rates, and vaccination coverage — producing a data-driven severity classification without any predefined labels.

The findings offer practical value for public health decision-makers: understanding which regions cluster together by severity profile enables more targeted resource allocation, vaccination campaign prioritization, and policy responses. The project includes comprehensive visual cluster analysis to make findings accessible to non-technical stakeholders.

Key Features

  • K-Means and Hierarchical Clustering — Both methods applied and compared, with the optimal K selected via the Elbow Method and Silhouette Score analysis.
  • Geographic Severity Mapping — Cluster labels mapped back to Ontario's public health unit boundaries to reveal spatial patterns in COVID-19 severity.
  • Resource Allocation Insights — Cluster profiles translated into actionable recommendations for healthcare capacity planning and vaccine distribution.
  • Visual Cluster Analysis — PCA-reduced scatter plots, dendrograms, heatmaps, and choropleth maps built with Seaborn and Matplotlib for intuitive interpretation.
  • Feature Engineering — Derived severity composite scores from raw epidemiological data, with standardization to prevent scale bias in clustering.

Tech Stack

Python K-Means Hierarchical Clustering Pandas Seaborn Scikit-learn Matplotlib NumPy

Results

The analysis identified three meaningful severity clusters across Ontario public health regions: low-severity, moderate-severity, and high-severity clusters with distinct epidemiological profiles. The high-severity cluster concentrated in the GTA and surrounding regions, consistent with population density patterns. Hierarchical clustering dendrograms confirmed the natural partitioning at k=3. The geographic mapping revealed clear spatial contiguity within clusters, validating the meaningfulness of the groupings and supporting targeted intervention strategies for regional health authorities.
