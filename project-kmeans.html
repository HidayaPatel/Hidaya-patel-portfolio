K-Means Clustering — COVID-19 Severity in Ontario

Unsupervised Learning · Public Health Analytics · Python

Overview

This project applies K-Means and Hierarchical clustering algorithms to COVID-19 case data across Ontario public health regions, with the goal of categorizing areas by severity and informing resource allocation decisions. Using Python's data science ecosystem, regional case metrics are clustered to reveal geographic patterns in outbreak intensity. Cluster profiles are visualized with Seaborn, and the dendrogram from hierarchical clustering validates the K-Means groupings. The insights support evidence-based public health planning by identifying which regions required the most urgent intervention.

Key Features

  • K-Means clustering for regional severity categorization across Ontario public health units
  • Hierarchical clustering for dendrogram-based validation of cluster structure
  • Geographic severity mapping across Ontario regions
  • Visual cluster analysis with Seaborn heatmaps and scatter plots
  • Resource allocation insights derived from distinct cluster profiles
